# Contributing to SagaTree

Beachte die [Lizenzstruktur](LICENSES.md).

- Eigener Code für die Plattform wird unter **AGPL-3.0-only** beigetragen; für ein später explizit separat veröffentlichtes SDK kann **Apache-2.0** gelten.
- Beiträge zum schriftlichen **SagaTree Core Rules**-Regelwerk werden unter der dortigen **ORC License** eingebracht. Das ORC Licensed Material und Reserved Material müssen unterscheidbar bleiben.
- Reiche ausschließlich eigene Inhalte oder Materialien mit nachweisbar ausreichenden Rechten ein. Nenne Quelle, Autor und Lizenz neu hinzugefügter Abhängigkeiten, Fonts, Bilder, Sounds und Modelle.
- Marketplace- und Creator-Inhalte werden nicht durch einen Softwarebeitrag automatisch AGPL- oder ORC-lizenziert.
- Urheberrechte verbleiben bei Beitragenden. Die Einreichung überträgt keine pauschalen Rechte zur proprietären Zweitlizenzierung; dies bedarf gesonderter Vereinbarungen.
- Folge den Architektur- und Prüfregeln aus [AGENTS.md](AGENTS.md).

Ein Pull Request sollte knapp erklären, welche Teile er verändert und ob neue Drittmaterialien/Lizenzpflichten entstehen.
